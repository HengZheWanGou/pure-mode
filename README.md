# B站专注模式

> 打开 B站主页，只保留搜索框。屏蔽所有推荐视频和板块，帮你专注学习。

> A browser extension that strips Bilibili's homepage down to just a search box — no feeds, no distractions.

---

## 功能介绍

你是否也遇到过这样的问题——打开 B站想查个资料、学个技能，结果主页上那些花花绿绿的推荐视频瞬间吸引了你的注意力？"就点进去看一眼"，然后不知不觉刷了几十分钟，原本的任务早就被抛到九霄云外。

**B站专注模式** 就是为了解决这个问题而生的。它把 B站主页精简到只剩一个搜索框，让你打开 B站时**只能搜索、无法刷推荐**，从源头消除分心。搜索结果页同样经过净化：广告、课程推广、底部推荐全部移除，只留干净的搜索结果。

## 预览

开启专注模式后，B站主页会变成这样：

- 干净的白色/深色/纸张背景
- 顶部粉色的 `bilibili` 标识
- 居中的搜索框，支持回车搜索
- 右上角你的头像（点击进入个人空间）
- 右下角一键切换主题

## 安装方法

### 方式一：Edge 加载项商店（推荐）

在 [Edge 加载项商店](https://microsoftedge.microsoft.com/addons) 搜索「适用于 bilibili 的专注模式」，点击「获取」即可，自动更新，Chrome 内核的浏览器（Edge / 360 / QQ 浏览器等）均可使用。

### 方式二：GitHub Release 下载安装（Chrome 用户推荐）

1. 打开本仓库的 [Releases 页面](../../releases)，下载最新版本的 `bilibili-focus-mode-vX.X.X.zip`
2. 解压到一个**固定的文件夹**（注意：解压后这个文件夹不能删除或移动，删了扩展就没了）
3. 打开 Chrome，地址栏输入 `chrome://extensions` 并回车
4. 打开页面右上角的「**开发者模式**」开关
5. 点击左上角「**加载已解压的扩展程序**」按钮
6. 在弹窗中选择刚才解压出来的文件夹（里面能看到 `manifest.json` 的那一层），点击「选择文件夹」
7. 安装完成！打开 [bilibili.com](https://www.bilibili.com) 即可生效
8. 建议点击扩展图标旁边的 📌 把它固定到工具栏，方便随时开关

> 💡 **常见问题**
> - 看不到「加载已解压的扩展程序」按钮？→ 说明开发者模式没打开，看第 4 步
> - 提示 "manifest 文件缺失"？→ 选错了文件夹层级，要选直接包含 `manifest.json` 的那层
> - 想更新版本？→ 下载新 zip 解压**覆盖原文件夹**，然后在 `chrome://extensions` 里点扩展卡片上的 🔄 刷新按钮

### 方式三：克隆源码加载（开发者）

```bash
git clone https://github.com/HengZheWanGou/pure-mode.git
```

然后按方式二的第 3–8 步，选择克隆下来的仓库文件夹即可。

## 使用说明

- **开启专注模式**：安装后自动生效，打开 B站主页即进入极简模式
- **切换主题**：点击页面右下角 ☀️🌙📄 按钮
- **禁用插件**：点击浏览器工具栏扩展图标 → 关闭开关 → 页面立即恢复原始 B站
- **搜索视频**：搜索框输入关键词，回车或点击图标跳转搜索结果

## 技术栈

- Chrome Extension Manifest V3
- Vanilla JavaScript（无框架依赖）
- CSS 变量动态主题
- MutationObserver 保护覆盖层

## 实现原理

插件采用**全屏覆盖层**方案：

1. `content.js` 在页面加载时注入一个固定定位的全屏 `div`，z-index 设为最大
2. 覆盖层内重建 Logo、搜索框、头像入口、主题切换按钮
3. 同时注入 CSS 隐藏规则，屏蔽 B站原页面的导航栏、Banner、推荐卡片等元素
4. `MutationObserver` 监控 body 变化，防止 B站框架移除覆盖层

头像获取采用三层回退策略：
- **优先**：B站 API `x/web-interface/nav` 获取当前登录用户头像
- **其次**：从 DOM 中查找已加载的头像元素
- **兜底**：2 秒后延迟重试，等 Vue 懒加载完成

搜索结果页采用**数据抽取 + 完全重排**方案（v1.2.0 起）：

1. `search.js` 隐藏原生页面，从 DOM 中抽取视频卡片数据（标题、封面、时长、播放量、UP主、日期）
2. 用插件自己的设计语言重新渲染结果网格，三主题与主页完全一致
3. 广告、直播、课程卡片不进入渲染流程（自然消除，不留空洞）
4. 「加载更多」通过 fetch 抓取下一页 HTML 解析追加，支持无限翻页
5. 顶部吸顶栏含 Logo、搜索框和主题按钮，与主页实时同步

视频播放页采用**保留骨架、切除肿瘤**方案（v1.3.0 起，播放器不可重建）：

1. 保留原生播放器、标题、工具栏、UP主卡片和视频选集，仅做主题化样式
2. 相关推荐与评论区默认折叠，点击开关可展开查看
3. 自动连播强制关闭（自动点击播放器设置中的「播完暂停」），播完不再跳进推荐坑
4. 隐藏顶部频道导航、播放结束页推荐、广告与运营位
5. 顶部替换为插件吸顶栏（Logo + 搜索框 + 主题按钮），三页主题实时同步

## 已知限制

- 支持 B站主页、搜索结果页（`search.bilibili.com`）与视频播放页（`/video/*`），其他子域名或移动端暂不兼容
- B站页面结构改版时可能需要更新选择器
- 部分浏览器（如 Firefox）需要额外适配 Manifest V2/V3 差异
