# B站专注模式

> 打开 B站主页，只保留搜索框。屏蔽所有推荐视频和板块，帮你专注学习。

---

## 功能介绍

你是否也遇到过这样的问题——打开 B站想查个资料、学个技能，结果主页上那些花花绿绿的推荐视频瞬间吸引了你的注意力？"就点进去看一眼"，然后不知不觉刷了几十分钟，原本的任务早就被抛到九霄云外。

**B站专注模式** 就是为了解决这个问题而生的。它把 B站主页精简到只剩一个搜索框，让你打开 B站时**只能搜索、无法刷推荐**，从源头消除分心。

## 预览

开启专注模式后，B站主页会变成这样：

- 干净的白色/深色/纸张背景
- 顶部粉色的 `bilibili` 标识
- 居中的搜索框，支持回车搜索
- 右上角你的头像（点击进入个人空间）
- 右下角一键切换主题

## 功能特性

| 特性 | 说明 |
|------|------|
| 🔍 **极简搜索** | 只保留搜索框，所有推荐内容全部消失 |
| 👤 **头像入口** | 右上角显示你的 B站头像，点击进入个人空间 |
| 🎨 **三主题切换** | ☀️ 纯白 / 🌙 深色 / 📄 纸张，一键切换 |
| 🔄 **即时开关** | 点击扩展图标随时启用/禁用，禁用后页面立即恢复 |
| 🎯 **精准作用域** | 只在 B站主页生效，不影响视频播放页、搜索结果页 |
| 💾 **状态记忆** | 主题偏好和开关状态自动保存 |

## 安装方法

### 方式一：Chrome 应用商店（推荐，暂未上架）

等待上架后可直接安装。

### 方式二：开发者模式加载（当前可用）

1. 下载本仓库，解压到本地文件夹
2. 打开 Chrome/Edge，地址栏输入 `chrome://extensions`（Edge 为 `edge://extensions`）
3. 右上角打开「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择 `bilibili-focus-mode` 文件夹
6. 安装完成，打开 [bilibili.com](https://www.bilibili.com) 即可生效

## 使用说明

- **开启专注模式**：安装后自动生效，打开 B站主页即进入极简模式
- **切换主题**：点击页面右下角 ☀️🌙📄 按钮
- **禁用插件**：点击浏览器工具栏扩展图标 → 关闭开关 → 页面立即恢复原始 B站
- **搜索视频**：搜索框输入关键词，回车或点击图标跳转搜索结果

## 技术栈

- Chrome Extension Manifest V3
- Vanilla JavaScript（无框架依赖）
- CSS 变量动态主题
- MutationObserver 保护覆盖层

## 实现原理

插件采用**全屏覆盖层**方案：

1. `content.js` 在页面加载时注入一个固定定位的全屏 `div`，z-index 设为最大
2. 覆盖层内重建 Logo、搜索框、头像入口、主题切换按钮
3. 同时注入 CSS 隐藏规则，屏蔽 B站原页面的导航栏、Banner、推荐卡片等元素
4. `MutationObserver` 监控 body 变化，防止 B站框架移除覆盖层

头像获取采用三层回退策略：
- **优先**：B站 API `x/web-interface/nav` 获取当前登录用户头像
- **其次**：从 DOM 中查找已加载的头像元素
- **兜底**：2 秒后延迟重试，等 Vue 懒加载完成

## 已知限制

- 仅支持 `www.bilibili.com` 主页（`/` 和 `/index.html`），子域名或移动端暂不兼容
- B站页面结构改版时可能需要更新选择器
- 部分浏览器（如 Firefox）需要额外适配 Manifest V2/V3 差异
